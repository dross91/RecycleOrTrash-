# RecycleOrTrash

A TypeScript-based project designed to help users decide whether an item should be recycled or thrown away.

## Overview

RecycleOrTrash is a simple app that can be extended to:
- classify common household items
- provide recycling guidance
- show disposal recommendations
- help users reduce waste by making smarter disposal decisions

## Features

- TypeScript codebase
- Clean project structure
- Easy to extend with new item categories
- Suitable for web, CLI, or app-based use cases

## Tech Stack

- TypeScript
- Node.js
- npm

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install dependencies

```bash
npm install
```

### Run the project

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
